## AquaTrack 💧

**AquaTrack — Gamified Water Conservation Monitoring Portal**

AquaTrack is a web-based water conservation portal designed around **UN Sustainable Development Goal 6 (SDG 6): Clean Water and Sanitation**. It combines water-usage monitoring, wastage/leak reporting, and gamification in one interactive interface.

The project was developed as a demonstration of how a digital platform can encourage users to monitor consumption, report water wastage, and participate in conservation activities.

## 🌊 Key Features

### 1. Overview
- SDG 6-focused landing page
- Water-conservation problem overview
- Target-user information
- Community impact indicators
- Explanation of the AquaTrack gamification workflow
- SDG 6 alignment cards

### 2. Dashboard & Meter Reading
- Enter previous and current meter readings
- Automatically calculate water consumption
- Convert consumption from cubic metres to litres
- Calculate an estimated daily usage rate
- View consumption trends using charts
- Switch between weekly and monthly chart views
- Search meter-reading history
- Delete individual entries or clear the history

### 3. Wastage / Leak Reporting
Users can submit water-wastage reports with:
- Location
- Issue type
- Severity level
- Description and additional details
- Optional photo evidence/preview
- Report status tracking

Supported issue types include pipe leaks, tank overflow, broken taps/valves, continuously running toilets, damaged irrigation sprinklers, and other water-wastage issues.

### 4. Gamification
AquaTrack encourages participation through:
- XP rewards
- Daily streaks
- Levels and titles
- Conservation badges
- Missions and quests
- Community leaderboard
- Separate leaderboard views for overall users, campus dorms, and facilities

Example rewards include **+25 XP for logging a meter reading** and **+50 XP for reporting water wastage**.

## 🔄 How It Works

The main conservation workflow is:

**Monitor → Report → Engage → Conserve**

1. Users record periodic water-meter readings.
2. AquaTrack calculates and displays consumption information.
3. Users can report leaks or other forms of water wastage.
4. Conservation actions earn XP and contribute to streaks, badges, and rankings.
5. The dashboard and community features provide feedback that encourages continued participation.

## 🛠️ Technologies Used

- **HTML5** — page structure and content

The supplied website is implemented as a frontend application and loads its external UI libraries through CDNs.

## 💾 Data & Demo Behaviour

The website is designed as a frontend demonstration. User interactions such as meter logs, reports, XP, and other application state are handled on the client side.

The interface also provides a **Reset Demo Local Data** control so the demonstration state can be reset when testing the application.

## 🎯 SDG 6 Alignment

AquaTrack is designed to support SDG 6 through:
- Encouraging responsible water use
- Improving awareness of water consumption
- Making water wastage easier to report
- Supporting water-use efficiency
- Encouraging community participation in water management

The website specifically presents connections to SDG 6 targets **6.1, 6.4, and 6.b**.

## 👥 Target Users

The portal is designed with several user groups in mind:

- **College students and dorm residents** — monitor usage and participate in conservation challenges.
- **Facility managers and plumbing teams** — receive and track water-wastage reports.
- **Residential communities and eco clubs** — encourage collective conservation and compare community performance.

## 🎓 Project Context

AquaTrack was developed as a Water Conservation Portal** project. The team's overall concept combines several possible approaches, including smart monitoring, leak detection, gamification, wastage reporting, predictive analytics, and automated water-management ideas. The final selected web solution is the **AquaTrack Gamified Water Conservation Monitoring Portal**.

## 📌 Limitations

The current implementation is primarily a demonstration/prototype:
- It does not include a real-time IoT water-meter connection.
- Leak detection is based on user reporting rather than physical sensors.
- The portal does not provide a production backend or multi-user authentication.
- Report updates are demonstrated within the web interface rather than through a connected facility-management system.
- The supplied project presents the website as a working demonstration rather than a deployed water-management infrastructure.

## 🚀 Possible Future Enhancements

- Connect real water meters or IoT sensors.
- Add user authentication and role-based access.
- Store data in a cloud database.
- Add real-time notifications for high-severity leaks.
- Introduce automated anomaly/leak detection from consumption data.
- Add facility-admin dashboards.
- Integrate real campus/residential water data.
- Add more detailed analytics and forecasting.
- Deploy the portal as a production web application.
